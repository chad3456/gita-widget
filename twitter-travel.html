Tweet Time Machine

Browse any account's tweets across any era — via the Internet Archive
@
How this works. This app queries the Internet Archive's public CDX API for archived captures of twitter.com/<handle>/status/*, then decodes each tweet's exact post time from its Snowflake ID. It shows only tweets that were archived — coverage is real but incomplete, and heavily-archived (popular) accounts return far more. No login, no API key.
Why not "every tweet"? Since 2023 there is no free, public API that returns an account's complete history; the official full-archive search is a paid enterprise product and can't be called from a static page. The Internet Archive is the honest free route to old (2012 and earlier) tweets.
